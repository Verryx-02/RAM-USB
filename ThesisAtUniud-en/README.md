# THUD: THesis at UniUD

THUD is a LaTeX format for degree theses in Computer Science and related fields at the Department of Mathematical, Computer and Physical Sciences of the University of Udine.

It is assumed that you know how to write in LaTeX; otherwise, [learn it](https://www.learnlatex.org/en/).

## Procedure for graduating

1. Clone or fork this repository.
2. Rename thesis.tex to thesis_*surname*.tex (with your surname), which will be the main file of the thesis. 
3. Edit the file thesis_*surname*.tex.  It is enough to fill in the required fields and add all the material you need. The code should be self-explanatory.
4. Compile thesis_*surname*.tex with pdflatex.
5. If you use bibtex (strongly recommended!): fill in the thud.bib file, run bibtex, then pdflatex and pdflatex.
6. Upload thesis_*surname*.pdf to Esse3 by the deadline.
7. Prepare the slides, optionally using the department's official format.
8. Present slide.pptx.
9. Get drunk with friends and family.
